# RADIOROC2 — ספקטרומטר גמא

קושחה ללוח NUCLEO-F722ZE המפעיל שבב RADIOROC2, יחד עם אפליקציית שולחן העבודה
בפייתון שמגדירה אותו, מבצעת מדידות ומשרטטת ספקטרומים.

כל מה שדרוש לבנייה נמצא כאן: מנהלי ה־HAL וכותרות ה־CMSIS מוטמעים בריפוזיטורי,
כך שאין צורך להוריד בנפרד חבילת firmware של STM32Cube.

**חדש כאן? קרא את הקובץ הזה כדי להריץ, ואז קרא את
[python/TOOLS_README.md](python/TOOLS_README.md) — זה המדריך האמיתי, והוא מכסה את
הפרוטוקול, כל פרמטר של ה־ASIC, סריקת הסף וטבלת פתרון הבעיות.**

---

## 1. מה צריך

| | |
|---|---|
| לוח | NUCLEO-F722ZE (STM32F722ZET6) |
| סביבת פיתוח | STM32CubeIDE — הבנייה כאן מאומתת על 2.1.1 |
| פייתון | 3.8 ומעלה, עם `tkinter` |
| כבל | כבל USB אחד ל־ST-Link. הוא נושא גם את הדיבאגר **וגם** את הנתונים |

אין מחבר USB נפרד לנתונים. הלוח משדר דרך **USART3 → ה־VCP של ה־ST-Link בקצב
921600**, וזה UART אמיתי ולא התקן CDC — ולכן קצב השידור באמת קריטי. הוא מוגדר
פעם אחת ב־[Core/Inc/usart.h](Core/Inc/usart.h) בשם `RR2_LINK_BAUD`, ומשוכפל
ב־`python/rr2_decode.py`.

## 2. הורדת הקוד

```bash
git clone https://github.com/noamkorinperi/radiocroc2_project.git
```

`main` הוא הענף הרצוי; הוא מכיל את הקושחה והתוכנה העדכניות.

## 3. בנייה וצריבה של הקושחה

1. **File → Open Projects from File System…**, הפנה אל התיקייה שהורדת, וייבא.
   שם הפרויקט ב־Eclipse הוא `RADIOROC2_Firmware` ללא תלות בשם שנתת לתיקייה.
   **אל** תשתמש במייבא של CubeMX — קבצי ה־`.project` וה־`.cproject` כאן כבר שלמים.
2. **Project → Build Project** (Ctrl+B). בנייה נקייה מסתיימת עם
   **0 שגיאות, 0 אזהרות** ומדווחת בערך `52356 text, 100 data, 12004 bss`.
3. חבר את הלוח ובחר **Run → Run As → STM32 C/C++ Application**. תצורת דיבאג
   מוכנה בשם `RADIOROC2_Firmware Debug` נמצאת בריפוזיטורי לצד הפרויקט.

תיקיית `Debug/` בכוונה אינה ב־git — CubeIDE מייצר אותה מחדש במלואה מהמקורות
ומה־`.cproject`.

### אם משנים את תצורת הפינים

פתח את [RADIOROC2_Firmware.ioc](RADIOROC2_Firmware.ioc) ב־CubeMX וייצר מחדש. אל
תערוך ידנית את הבלוקים המיוצרים ב־`gpio.c`, `tim.c` או `adc.c`, כי ה־generate
הבא ימחק את השינויים בשקט. כל תוספת משלך הולכת בין הסימונים
`USER CODE BEGIN` / `USER CODE END`.

## 4. הרצת אפליקציית שולחן העבודה

```bash
cd python
pip install -r requirements.txt
python rr2_gui.py
```

רק `pyserial` הכרחי באמת. `openpyxl` ו־`pillow` אופציונליים: בלעדיהם ייצוא Excel
נופל חזרה ל־CSV וכפתור הצילום מסביר את עצמו, ושום דבר אחר לא משתנה.

### לנסות בלי חומרה

```bash
python rr2_gui.py --sim
```

מצב סימולציה מייצר פוטו־פיק גאוסיאני עם זנב דמוי־קומפטון בקצב של בערך 180
ספירות לשנייה. זו הדרך המהירה ביותר ללמוד את הממשק לפני שהלוח על השולחן.

### בדיקת הקישור

```bash
python rr2_decode.py --list
```

הפקודה מציגה את הפורטים הטוריים ומסמנת מי מהם ה־ST-Link. שני הכלים מזהים את
הלוח לפי VID/PID של ה־USB, כך שאף פעם אין צורך לדעת את מספר ה־COM — שממילא
משתנה בין שקעי USB.

## 5. מבנה הריפוזיטורי

```
Core/          קושחה. קוד האפליקציה הוא radioroc2*.c; השאר הוא פלט של CubeMX
Drivers/       HAL של STM32F7 ו-CMSIS, מוטמעים
python/        כלי צד מחשב — התחל מ-TOOLS_README.md
  rr2_gui.py       אפליקציית שולחן העבודה; את זה מריצים
  rr2_decode.py    פרוטוקול המסגרות; חייב לשבת ליד ה-GUI
  rr2_thscan.py    מנוע סריקת הסף, וגם כלי שורת פקודה בפני עצמו
  rr2_i2ctest.py   בדיקת קישור ה-Slow Control
*.ioc          תצורת CubeMX
*.ld           סקריפטי לינקר
```

מדידות, לוגים גולמיים של אירועים, סריקות סף וצילומי מסך נכתבים ליד סקריפטי
הפייתון וכולם ב־gitignore — אלה נתוני מעבדה, לא קוד מקור.

## 6. מפגש ראשון

1. צרוב את הקושחה, ואז הפעל את `rr2_gui.py`.
2. **Main** → בחר פורט → **Connect**. מחוון הקישור אמור להפוך לירוק תוך שנייה או
   שתיים; הלוח שולח מסגרת סטטוס כל שנייה, בין אם מודדים ובין אם לא.
3. **Settings** → הפעל את הערוץ שבשימוש → **Apply global**.
4. **Scan** → **Start scan** כדי למצוא איפה קצב הספירה מפסיק להיות המקור ומתחיל
   להיות רעש, ואז קבע את הסף שהיא ממליצה עליו.
5. **Measure** → מלא **Run label** ואת תנאי הריצה → **Start**.
6. **History** → בחר את הריצה → **Export to Excel**.

הקושחה כבר מחילה באתחול את גיטור הערוצים ואת `Preset CsI`, כך שאין צורך לעשות
אף אחד מהם ידנית. `stat` אמור לדווח `hold_ns` סביב 5900 בתצורת CsI — אם הוא מראה
3000, ה־preset לא נכנס.

## 7. כשמשהו לא עובד

[python/TOOLS_README.md](python/TOOLS_README.md) מסתיים בטבלת תסמין/סיבה שמכסה את
התקלות הנפוצות. השתיים שתופסות אנשים ראשונות:

- **מחובר אבל מתקבל ג׳יבריש** — קצב השידור לא תואם. הקישור הזה הוא UART אמיתי
  ב־921600, לא פורט CDC שמתדיין על הקצב.
- **המחוון ירוק אבל `Test link` לא נענה** — מסגרות מגיעות אבל פקודות לא נוחתות,
  ולכן הגדרות ייראו כאילו הוחלו ולא יוחלו.
